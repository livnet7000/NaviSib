        Вы имеете право:
           Использовать приложение в любых целях.
           Распространять неизменные копии приложения.
        Запрещается:
           Модифицировать, дорабатывать или создавать производные работы на основе исходного кода.
           Обратно проектировать, декомпилировать или дизассемблировать приложение.
